# 수도권 머니 플라이트

수도권 77개 시군구(서울 25구 · 인천 10군구 · 경기 42시군구) 사이에서 아파트 매매 자금, 전월세 보증금, 인구가
어디서 어디로 움직이는지 항공 관제판처럼 보여주는 정적 웹 서비스.

```
python3 pipeline/run.py demo        # → dist/index.html (데모 데이터)
MOLIT_KEY=... python3 pipeline/run.py real --from 2024-01 --to 2026-08
```

## 구조

```
pipeline/
  build_geo.py       행정동 경계 → 시군구 병합·단순화 (data/regions_geo.json)
  regions.py         시군구 앵커 좌표(아파트 밀집지 보정), 데모용 사전값
  sources/molit.py   국토부 실거래 매매·전월세 API → 시군구·월 집계
  sources/reb.py     부동산원 매입자거주지별 매매 CSV → 버킷 비중
  sources/mdis.py    통계청 인구이동 마이크로데이터 → 시군구 OD (주택 사유)
  synth.py           위 3개와 '같은 스키마'의 데모 중간 테이블 생성
  build_flows.py     중간 테이블 → 흐름 추정 → data/flows.json
  build_web.py       flows.json 인라인 → dist/index.html
web/template.html    UI (Canvas 2D, 외부 JS 의존성 없음)
```

데이터는 월 1회 갱신되므로 상시 API 서버 없이 **월 배치 → 정적 파일 → CDN** 구조로 충분하다.
API 서버가 필요해지는 시점은 기간·필터 조합이 커져 단일 JSON(현재 1.6MB)이 수십 MB를 넘을 때다.
그때는 flows를 `(ym, layer)` 단위로 분할하거나 DuckDB + Parquet 기반의 얇은 조회 API를 둔다.

## 흐름 추정 방법

실거래 자료에는 매수자의 출발지가 없다. 따라서 **인구 이동만 실측 OD이고, 매매·전월세는 추정**이다.

- 매매: `F(i→j) = 거래건수(j) × 매입자거주지비중(j, 버킷) × 이주OD(i→j) / Σ버킷 이주OD`
  - 버킷: 관할 시군구 내 / 관할 시도 내 / 서울 / 기타 (부동산원 분류)
  - 이주 OD는 최근 12개월 누적 (단월 OD는 소규모 시군에서 노이즈가 큼)
- 전월세: 신규 계약만 사용 (갱신은 이사가 없음), 이주 OD 비율로 출발지 배분

## 데이터 품질 처리

| 문제 | 처리 |
|---|---|
| 계약 해제 신고 | `cdealType == 'O'` 제외 |
| 전월세 갱신 계약 | 흐름에서 제외, 집계에는 포함 |
| 부천시 2024 구 재설치 (41192/4/6) | 41190으로 병합 |
| 실거래 신고기한 30일 | 최근 2개월 '잠정' 표시 |
| 넓은 시군의 기하 중심 (화성 → 서해안) | 아파트 밀집지 앵커로 보정 |
| 비수도권 집계 노드 과대 표시 | 기본 꺼짐, 끄면 지도 색·KPI에서도 비수도권분 제외 |

## 한계

- 거래금액 ≠ 실제 이동 현금 (대출·승계 전세금 포함)
- 법인·외국인 매수 미구분
- 부동산원 R-ONE 통계표 ID는 개편 시 바뀌므로 CSV 수동 다운로드를 기본으로 둠
- MDIS 전입사유 코드는 연도별 코드표 확인 필요 (`sources/mdis.py: HOUSING_REASON`)
- 경계 자료는 2023.07 기준
